# PowerUnit Research

Working repository for a 1/10-scale hybrid RC powertrain: a Toyan FS-L200AC 7cc
twin-cylinder four-stroke paired with a crank-mounted electric motor-generator
(F1 MGU-K style), managed by ESP32-based telemetry and, later, custom ignition-timing
control — finishing in a self-designed 3D-printed chassis with instrumented aero.

Synced between desktop PC and laptop via this repo. Pull before working, push after.
