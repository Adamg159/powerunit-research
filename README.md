# PowerUnit Research

Working repository for a 1/10-scale hybrid RC powertrain: a Toyan FS-L200AC 7cc
twin-cylinder four-stroke paired with a crank-mounted electric motor-generator
(F1 MGU-K style), managed by ESP32-based telemetry and energy management —
finishing in a self-designed 3D-printed chassis with instrumented aero. (A custom
ignition-timing ECU is a deferred stretch goal.)

Synced between desktop PC and laptop via this repo. Pull before working, push after.

**Status (2026-08-05):** engine on backorder until late August; build re-sequenced
to work around it (steering, MGU-K electrical, firmware, transmission, chassis
packaging, bench surrogate rig). See [CLAUDE.md](CLAUDE.md) for the governing plan.
