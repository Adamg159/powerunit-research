Section 1Current status

Phase 1 purchasing has begun. The telemetry and control-electronics order has since been placed as well ($205 actual, itemized with prices in Section 4). Nothing on the deferred list requires more than a few days’ shipping, so this ordering strategy costs no schedule time and eliminates the risk of buying incompatible parts.

Section 5Build sequencing rules

Three rules govern the first weeks and exist to keep failure modes separated. First, the engine is assembled and broken in on its stock glow ignition with nitro fuel, tuned to a steady idle and clean throttle response, before the gasoline/CDI conversion is installed — so that engine problems and conversion problems can never be confused with one another. Second, the CDI conversion is installed only after adding the high-voltage ground strap (a known defect in the current kit revision that otherwise destroys the Hall sensor and ignition module). Third, per the manufacturer’s manual: the cam box is greased before first start, the engine is never run wide-open with no load, starting attempts are limited to short bursts, and all running happens outdoors.

ESP32 data logging (cylinder-head temperature and RPM) is brought online from the first start, so the baseline dataset that informs Phase 2 design decisions accumulates from day one. With ignition-timing control now a core objective, Phase 1 also records the CDI kit’s Hall crank-trigger waveform through an opto-isolated tap, giving the Phase 2 ignition controller real captured signals to be developed against. The engine itself runs entirely on the stock fixed-timing CDI throughout Phase 1; the sequencing rules above are unchanged.

Section 6Phase 1 completion criteria

Phase 1 is complete when the engine is assembled with timing verified; runs and tunes reliably on glow ignition; runs on gasoline with the CDI conversion and ground-strap fix installed; and a full run of head-temperature, RPM, vibration, and crank-trigger data has been logged. That dataset, together with the documented build log, is the deliverable that gates Phase 2 (electric motor-generator integration) and supports the budget request for the later stages.
